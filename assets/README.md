# Asset provenance

Official COWMATA logo files are reused from the companion recognition repository for the same company project. They remain proprietary under [NOTICE](../NOTICE).

`figures/risk-en.svg` and `figures/risk-zh.svg` are bilingual architecture figures for the current auxiliary modules and planned fusion. The generator is maintained in the [system hub](https://github.com/zxq309/cowmata/blob/main/scripts/build_diagrams.py).

The activity PNG under `modules/activity/说明/图表` is an imported historical experiment figure. It represents exploratory data, not new validation. Original module-file hashes remain in [import-manifest.json](../docs/import-manifest.json).

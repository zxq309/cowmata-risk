# Decision roadmap / 决策路线图

1. Current: independently runnable temperature 0.6.0 and activity 1.0.0 evidence modules, with schemas and persistent state.
2. Next: adapter for behavior events, common identity/time semantics and missing-evidence handling.
3. Then: define fusion using fixed cow/calving splits, evaluate continuous negative coverage and alert lead time.
4. Later: estrus, pregnancy and health tasks as modules with their own ground truth and validation.

当前已有两个辅助模块；下一步先统一行为事件适配、身份与时间语义，再做融合与独立验证。露蹄和完全娩出分别记录，不混用提前量锚点。尚不建立空的“已完成算法”目录或承诺统一预警性能。
